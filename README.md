
# Topo Trails

Topo Trails is a free browser game that teaches students to read topographic maps. A live ArcGIS Online topo map fills the top of the screen; below it, students ride a motorcycle across the real elevation profile of a route line drawn on that map. Students search any location, draw their own route with two taps, and immediately ride its true terrain, built from real elevation data. Learning goals: interpret contour lines and intervals; connect closely spaced contours with steep slopes; relate map views to elevation profiles; read elevations in feet; and make and test predictions about landforms. Grades 3–8.
